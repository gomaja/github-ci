# Security Policy

## Reporting A Vulnerability

Do not disclose suspected vulnerabilities in a public issue. Report them with
GitHub private vulnerability reporting for this repository.

Include the affected component and version, impact, reproduction steps, and any
known mitigation. Reports will be acknowledged after they have been reproduced
and assessed.

## Supported Versions

Until the first stable release, only the current `main` branch is supported.
After `v1.0.0`, the latest stable minor release will receive security fixes.
