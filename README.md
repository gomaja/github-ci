# github-ci

`github-ci` provides reusable, zero-finding GitHub Actions workflows and
repository-governance tooling for public open-source projects.

The project is currently in design review. Its committed design is in
[`docs/superpowers/specs/2026-08-18-github-ci-design.md`](docs/superpowers/specs/2026-08-18-github-ci-design.md).
