# github-ci v1.1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the unadopted v1.0.0 workflow contract with a complete
schema-2 execution model and exact-commit release acceptance, published later
as v1.1.0.

**Architecture:** Strict YAML configuration resolves once into immutable
per-module Go execution plans. Standard and deep workflows consume canonical
JSON argument arrays, while consumer-owned jobs handle private authentication,
generation, and services. A release-candidate workflow binds local
standard/deep runs and external trusted/fork canaries to one candidate SHA
before release evidence can be produced.

**Tech Stack:** Go 1.25/1.26, Bash, GitHub Actions reusable workflows, strict
YAML/JSON, GitHub REST API, actionlint, gopls, staticcheck, golangci-lint.

**Spec:** `docs/superpowers/specs/2026-08-19-github-ci-v1.1-design.md`

## Global Constraints

- `v1.1.0` is an intentional pre-adoption compatibility reset; configuration schema 1 is rejected.
- The existing `v1.0.0` tag and GitHub Release are never moved, recreated, or deleted.
- No tag, release, push, pull request, repository creation, or governance
  mutation occurs without the corresponding explicit authorization.
- Every Go behavior uses test-first red, green, refactor and deliberate mutation verification.
- Shell execution uses arrays and quoted expansion; `eval`, command-string
  construction, and consumer-provided commands are forbidden.
- Existing evidence completeness, action SHA pins, image digests,
  least-privilege permissions, attestations, and fail-closed behavior remain
  intact.
- Private authentication, repository-specific generation, services, protocol
  tests, and system tests remain consumer-owned required jobs.
- Full Go validation after changes is `go build ./...`,
  `go test ./... -count=1`, `go vet ./...`, `~/go/bin/staticcheck ./...`,
  `~/go/bin/golangci-lint run ./...`, `~/go/bin/goimports -l`,
  `~/go/bin/gopls check`, and `go test -race ./... -count=1`.
