# Contributing

Changes are made through pull requests against `main`.

Contributions must include focused tests, update generated artifacts when their
sources change, and pass every applicable required check with no open findings.
Tool suppressions and policy exceptions require a narrow scope, a technical
rationale, an owner, and an expiry date.

Security vulnerabilities must be reported according to [`SECURITY.md`](SECURITY.md).
By submitting a contribution, you agree that it is licensed under Apache-2.0.
